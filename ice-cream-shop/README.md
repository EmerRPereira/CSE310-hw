# Ice Cream Shop - SQL Relational Database Integration

## Overview

As a software engineer, I developed this application to deepen my understanding of SQL relational databases and their integration with Kotlin. This project demonstrates how to build a complete data persistence layer using PostgreSQL and JDBC, implementing real-world database operations beyond simple CRUD.

The software is a **console-based Ice Cream Shop Management System** that manages customers, products, and orders through an interactive interface. It showcases practical database integration with features like complex JOIN queries, aggregate functions, transaction management, and real-time data validation.

**Purpose:** To master the integration of SQL databases with Kotlin applications while implementing professional software patterns like Repository and Service layers.
